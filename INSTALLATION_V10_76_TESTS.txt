VINTED SNIPE V10 — INSTALLATION
===============================

1. Remplace les fichiers du dépôt par ceux du paquet, sans modifier les noms.
2. Place vinted-scan.yml dans .github/workflows/vinted-scan.yml.
3. Conserve ton secret GitHub NTFY_TOPIC.
4. Lance Actions > Vinted Scan > Run workflow.

----------
- correction dynamique des fautes par distance de Levenshtein ;
- protection des références courtes/chiffrées : PS4 ne devient jamais PS5 ;

- cache des règles persistant dans runtime_data/searches_cache.json ;
- rapport de performance avec débit, temps réseau cumulé et régression 30 j ;
